## Overview

**Winter Arc 2026** is a focused period of consistent daily effort toward personal and professional growth. This web application provides a single, interactive interface to plan and monitor that progress, so nothing falls through the cracks.

Instead of scattering goals across notes, spreadsheets, and apps, the tracker brings the key areas of a disciplined routine together in one place.

**Live application:** https://auth-flow-inky-six.vercel.app/

## Features

| Area | Description |
|------|-------------|
| **Daily Habits** | Log and review habits on a day-by-day basis |
| **DSA Practice** | Track Data Structures & Algorithms problems and topics covered |
| **Projects** | Monitor the progress of ongoing builds and deliverables |
| **Career Goals** | Keep long-term objectives visible and measurable |
| **Adaptive Theme** | Supports both light and dark color schemes |
| **Responsive UI** | Optimized for desktop and mobile screens |

## Getting Started

### Prerequisites

- A modern web browser
- [Node.js](https://nodejs.org/) (v18 or later) — only required if the project uses a build step

### Installation

```bash
# Clone the repository
git clone https://github.com/laiba-saghir/<repository-name>.git

# Navigate into the project directory
cd <repository-name>
```

### Running Locally

**Static version:** open `winter-arc.html` directly in your browser.

**With a dev server (if applicable):**

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:3000`.

## Deployment

The project is deployed on Vercel. To deploy your own instance:

1. Push the repository to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Click **Deploy**. Vercel will handle the build and hosting automatically.
